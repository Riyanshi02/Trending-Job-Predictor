# 📌 Trending Job Predictor

## 📖 Project Description
Trending Job Predictor is a machine learning–based system that predicts a student's placement chances, potential company, and job role based on academic performance and skills. It also suggests skills to improve employability.

---

## 🎯 Features
- Predicts placement probability
- Suggests companies and job roles
- Skill gap analysis and recommendations
- Placement analytics dashboard
- Student career guidance support

---

## 🛠 Technologies Used
- Python
- Machine Learning (Scikit-learn)
- Pandas, NumPy
- Streamlit (for web app)
- Matplotlib / Plotly (visualizations)

---

## 📊 Dataset Information
Dataset contains student details such as:
- CGPA
- Branch
- Skills
- Internship count
- Projects
- Certifications
- Placement status
- Company & Job role

---

## 🚀 How to Run the Project
1. Clone the repository
2. Install dependencies:
```bash
pip install -r requirements.txt
```
4. Run the app:
```bash
streamlit run main.py
```
